安装指引

三步开始。

  1. 01打开 DMG

    下载完成后，打开 Famorise 安装镜像。

  2. 02拖入应用程序

    将 Famorise 拖到 Applications 文件夹。

  3. 03导入家庭照片

    首次启动后选择本地图库，开始端侧理解。

01签名清单验证

官网先验证版本、平台、架构、有效期与 Ed25519 签名，再进入下载。

02完整性可追溯

每个发布产物都绑定 SHA-256、文件大小和更新签名。

03本地数据独立保存

覆盖安装只更新应用；家庭图库与本地工作区不放在 DMG 中。

其他平台

Windows 与 Linux 版本将在完成对应签名、安装和升级验收后开放。
